Skill Launcher

Click a skill. Its command is copied, the target page opens if it has one, then open Claude in Chrome and paste.

How the link format works

?skill=start highlights one skill so a bookmark lands on it. ?text=/my-shortcut%20extra%20words builds a one-off card with any command. &open=https://... adds a page to open before you run it. Chrome only lets a page write to the clipboard after a click, so one click is always required.

Set a keyboard shortcut for the extension at chrome://extensions/shortcuts so opening the side panel is one keystroke instead of a trip to the toolbar.
